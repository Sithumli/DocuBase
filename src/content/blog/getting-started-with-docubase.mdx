## Project Structure

DocuBase organizes your content into three main types:

### Documentation Pages

Perfect for reference material, API docs, and guides. These live in `src/content/docs/` and support categorization and ordering.

### Blog Posts

Share updates, announcements, and articles. Blog posts are in `src/content/blog/` and are sorted chronologically.

### Tutorials

Step-by-step learning content with difficulty levels and prerequisites. Find these in `src/content/tutorials/`.

## Key Features

DocuBase comes packed with features that make documentation a breeze:

### MDX Support

Write in Markdown with the power of components. Import and use any Astro component directly in your content.

<Callout type="tip">
MDX allows you to create interactive examples right in your documentation pages!
</Callout>

### Built-in Components

Use pre-built components like callouts, tabs, code groups, and more without any setup.

### Type-Safe Content

Content collections provide full TypeScript support, catching errors before they reach production.
