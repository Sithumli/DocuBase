## Why DocuBase?

DocuBase is built with modern web technologies and designed for developers who want:

- **Fast Setup** - Get started in minutes
- **Beautiful Design** - Professional look out of the box
- **MDX Support** - Use React/Astro components in Markdown
- **Type Safety** - Full TypeScript support
- **Easy Deployment** - Works with all major platforms

## Prerequisites

Before you begin, make sure you have:

- Node.js 18 or higher
- A package manager (npm, pnpm, or yarn)
- Basic knowledge of Markdown
- A code editor (VS Code recommended)
