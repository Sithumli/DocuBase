# Content Creation

Learn how to create engaging documentation with DocuBase's powerful content features.

## Writing in MDX

DocuBase uses MDX, which combines Markdown with component support:

```mdx
---
title: My Page
description: Page description
---

import MyComponent from '@/components/MyComponent.astro';

## Regular Markdown

This is normal markdown content.

<MyComponent />
```

## Frontmatter

Every content file starts with frontmatter:

```yaml
---
title: Page Title         # Required
description: Brief desc   # Recommended
pubDate: 2026-01-18      # For blogs/tutorials
tags: [tag1, tag2]       # Optional
order: 1                 # For ordering
draft: false             # Hide from production
---
```

<Callout type="warning">
Always include a title and description for better SEO!
</Callout>

## Content Best Practices

1. **Write clearly** - Use simple, direct language
2. **Structure well** - Use headings hierarchically
3. **Add examples** - Show, don't just tell
4. **Use components** - Enhance with callouts and tabs
5. **Test links** - Ensure all links work

## Multi-Page Series

To create a multi-page series like this guide:

1. Create a folder: `blog/my-series/`
2. Add pages with `series: "my-series"` in frontmatter
3. Use `order: 1, 2, 3...` to sequence pages
4. First page (order: 1) is the overview
