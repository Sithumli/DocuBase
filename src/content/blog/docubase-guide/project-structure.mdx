# Project Structure

DocuBase uses a well-organized folder structure that makes it easy to manage your documentation.

## Main Directories

```
docubase/
├── src/
│   ├── content/          # Your documentation content
│   │   ├── docs/        # Documentation pages
│   │   ├── blog/        # Blog posts
│   │   └── tutorials/   # Tutorial content
│   ├── components/      # Reusable components
│   ├── layouts/         # Page layouts
│   ├── pages/           # Route pages
│   └── styles/          # Global styles
├── public/              # Static assets
└── package.json         # Dependencies
```

## Content Organization

DocuBase organizes content into three main types:

### Documentation Pages

Located in `src/content/docs/`, these are perfect for:
- API references
- User guides
- Technical specifications
- FAQs

### Blog Posts

Found in `src/content/blog/`, ideal for:
- Release announcements
- Tutorials and guides
- Company updates
- Technical articles

<Callout type="tip">
Blog posts can be organized into multi-page series like this guide!
</Callout>

### Tutorials

Stored in `src/content/tutorials/`, great for:
- Step-by-step learning paths
- Hands-on workshops
- Interactive exercises

## File Naming

- Use lowercase with hyphens: `getting-started.mdx`
- Be descriptive: `api-authentication.mdx` not `auth.mdx`
- For multi-page content, use folders: `blog/guide-name/index.mdx`

## Configuration Files

Key configuration files:

- `astro.config.mjs` - Astro configuration
- `src/content.config.ts` - Content collection schemas
- `tsconfig.json` - TypeScript settings
- `package.json` - Project dependencies
