We're excited to announce the launch of DocuBase, a general-purpose documentation template designed for web projects of any size.

## Why DocuBase?

Documentation is crucial for any project, but setting up a documentation site from scratch can be time-consuming. DocuBase provides a ready-to-use template that includes:

- **MDX Support**: Write documentation using Markdown with embedded components
- **Multiple Content Types**: Documentation pages, blog posts, and tutorials out of the box
- **Framework-Agnostic**: Works with any UI library or none at all
- **Static Site Generation**: Fast, SEO-friendly pages that deploy anywhere

## Key Features

### Content Collections

Astro's Content Collections provide type-safe content management. Define your schemas once and get full TypeScript support throughout your project.

### Reusable Components

DocuBase includes a set of commonly-needed components for technical documentation:

- Callouts for notes, warnings, and tips
- Tabs for organizing related content
- Code groups for showing multiple code examples
- Steps for sequential instructions
- Collapsible sections for detailed content

### Tailwind CSS Styling

All components are styled with Tailwind CSS, making customization straightforward. Want to change the primary color? Just update the CSS variables.
