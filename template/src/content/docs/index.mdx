Welcome to DocuBase! This quick start guide will have you up and running with a beautiful documentation site in just a few steps.

## One-Minute Setup

<Steps>
  <Step title="Create your project">
    ```bash
    npx create-docubase my-docs
    cd my-docs
    ```
  </Step>

  <Step title="Start the dev server">
    ```bash
    npm run dev
    ```

    Open `http://localhost:4321` in your browser.
  </Step>

  <Step title="Create your first page">
    Add a new file at `src/content/docs/my-page.mdx`:

    ```mdx
    ---
    title: My First Page
    description: A new documentation page
    ---

    # Hello World

    This is my first documentation page!
    ```
  </Step>
</Steps>

<Callout type="tip" title="Hot reload">
Changes to your MDX files are automatically reflected in the browser—no refresh needed!
</Callout>
