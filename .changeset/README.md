# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [in the changesets repository](https://github.com/changesets/changesets)

**You probably don't need to manually edit files in this folder.**

## Adding a changeset

Run `pnpm changeset` to create a new changeset. This will:
1. Ask which package changed (we only have one: `create-docubase`)
2. Ask what kind of change: `patch`, `minor`, or `major`
3. Ask for a short description

The changeset file gets committed with your PR.

## What happens on merge

When your PR merges to `main`, the release workflow will:
1. Collect all changeset files
2. Bump the version accordingly
3. Update CHANGELOG.md
4. Publish to npm
